# ohno

Windows x64 课堂助手：原生 C++17 Win32 自启动服务、纯 Go 原生内网教师 Web 管理端和学生申请窗口。全仓库**零 Python、零 .NET、零外部运行库依赖**。

## 快速开始（直接下载发行版）

从 GitHub Releases 下载对应附件并核对 `SHA256SUMS`：

1. **教师机**：双击 `ohno-teacher.exe`（Linux 教师服务器可使用 `ohno-teacher-linux-amd64.tar.gz`）。程序自动检测本机局域网 IPv4、签发包含全部局域网 IP SAN 的 HTTPS 证书、初始化本地状态与本校发布信任，并启动两个完全分离的入口：
   - `http://127.0.0.1:8765`：**仅在教师机本地开放**的管理页，自动在浏览器打开，**无后台登录密码**（CSRF 防护）。
   - `https://<教师机IP>:8443`：仅面向学生端设备注册、引导证书指纹、策略同步、审批申请与托管升级的局域网 API；不暴露任何教师管理页面。
2. **设置维护密码并获取安装器**：在本地管理页顶部「学生机快速部署」卡片设置独立的**教师维护密码**，按需选择局域网 IP 下载本校专属 `Ohno-School-Setup.exe`（只包含 API 地址、公开证书和发布验证公钥，不含密码或私钥）。若局域网 IP 变化，可在页面一键重新签发证书并热重载。
3. **学生模板机安装（二选一）**：
   - **专属安装包（推荐）**：复制 `Ohno-School-Setup.exe` 到学生模板机双击、允许 UAC、输入教师维护密码即可一键安装 `Ohno` 服务（位于 `C:\Program Files\Ohno`）并自动启动。
   - **通用安装包**：直接运行 `ohno-setup.exe`，输入教师端 IP（如 `10.181.203.70`），点击「连接教师端」自动拉取证书并核对 SHA-256 指纹，输入维护密码即可安装，无需手动寻找 `.pem` 文件。
   维护密码绝不进入安装包或镜像；镜像克隆开机不重复输入。设备随后出现在教师页，由教师批准并绑定 MAC。

“现场临时解锁”与后台权限彻底分开：教师页可选设置 4–8 位数字 PIN，仅用于学生机现场暂停限制 1 小时；默认关闭，加盐哈希保存。

教师机 TCP 8443 需允许学生网段访问（管理页提供一键复制的 Windows 防火墙放行命令）。管理口 8765 只监听 `127.0.0.1`，不应开放到局域网。部署至目标精简 Windows 10、兆芯实机或联想 OEM 增量镜像前，建议先在可恢复测试机完成现场验证，见 [隔离试用指南](docs/trial-guide.md)。

## 核心特性

- **零依赖原生发行**：学生端为 `/MT` 静态链接的 C++17 Win32 原生程序；教师端为 Go 1.24 标准库静态编译的原生单文件程序（零第三方 Go 依赖，零 Python / PyInstaller）。
- **单窗口高分屏安装与自动证书固定**：支持 PerMonitorV2 DPI 与系统字体；可通过 IP 自动拉取并核对教师证书 SHA-256 指纹；仅在应用内固定公开证书与发布公钥，不向整机 Root 证书库新增信任。
- **程序多维特征识别（防改名）**：除文件名与 SHA-256 外，原生提取 PE `VersionInfo`（原始文件名、产品名、公司名、文件描述、内部名）、Authenticode 数字签名者与可见顶层窗口标题，支持 `orig:`、`product:`、`company:`、`desc:`、`signer:`、`title:`、`path:` 特征规则，改名绕过无效。
- **网站与程序黑名单 / 白名单双模式**：网站与程序策略可分别切换黑名单模式或白名单模式；程序白名单自动保护 Windows 系统目录、Session-0 服务与 Ohno 自身；审批请求支持「允许 1 小时」或「永久加入白名单」。
- **托管升级与持久回滚**：单一 SCM 服务 `Ohno` 拉取教师显式签名批准的 `OHNOPK01` 不可变包，经完整哈希、签名、独立暂存、在线执行授权与私有健康检查提交，失败自动回退且不降低防重放序号。
- **设备识别不依赖 DHCP IP**：优先使用物理有线网卡永久 MAC，结合 SMBIOS UUID 识别镜像克隆，每台设备使用独立凭据认证。
- **网络与浏览器策略**：单服务托管随包携带的 sing-box 1.14.4（Wintun）TUN 与 Edge 策略；支持实验性 WFP 来源联网限制、桌面申请窗口（`LocalSystem` 属主命名管道 + 后台可取消 I/O）与可选课堂 PIN 临时解锁。

## 安全边界

学生拥有管理员权限时可以停止服务或修改系统设置。MAC 可被伪造，不作为认证密钥；更换网卡、重新分发镜像或从旧版 `OhnoPrototype` 迁移时需重新审批。程序监视存在启动后扫描窗口，WFP 下载来源标记并非防病毒功能。详见 [托管升级与维护授权](docs/managed-updates.md)。

## 从源码构建与测试

构建与测试仅需 C++17 编译器（Linux `g++` / Windows MSVC）、Go 1.24+ 与 Node.js（前端脚本测试），**不需要 Python**：

- `make test`：校验零 `.py` 文件、运行全部 C++17 核心测试、Go 教师端测试（含 `-race`）、Go/C++ 包格式一致性测试与前端更新 UI 测试。
- `make ohno-teacher ohno-pkg`：编译原生教师端与 `ohno-pkg` 更新包打包器。
- `.github/workflows/release.yml`：完整的 Linux / Windows x64 原生编译、WFP、Edge、TUN、SCM 服务、托管升级与回滚端到端验证及正式发行打包。
