# ohno v0.1.0-alpha.3

**安装方式改为直接双击，不再要求用 shell 输入安装命令。**

- 教师端 `ohno-teacher.exe` 直接启动：首次运行自动初始化 HTTPS 证书、配置文件，显示一次随机管理密码并打开 Web 管理页。
- 登录后的教师网页提供 **Ohno-School-Setup.exe** 下载：生成学校专属单文件安装器，内置教师服务器地址和公开证书，**不包含教师密码或私钥**。
- 学生机双击学校专属 EXE，允许 UAC 后自动写入服务、TUN 组件及学生申请窗口，并启动服务等待教师批准。
- 公版 `ohno-setup.exe` 双击会打开原生 Win32 安装界面，填写服务器 HTTPS 地址和证书；不再是命令行-only。
- 增加学校安装包生成、解析及实际 Windows 安装的自动化测试。发布资产增加可直接双击的独立 EXE，而非只有 ZIP。

注意：教师服务需保持运行，监听 TCP 8443；其 Windows 主机名必须在学校内网可解析。学校专属包会将自签的教师证书加入学生机**整机受信任根证书存储**，学校 IT 应核实其可信性。若已经安装旧版客户端，先验证现有卸载与重新安装流程；本版暂不支持可靠的原位升级。

**仍为隔离测试版**：兆芯 Win10 和联想增量镜像流程尚未现场验证；管理员权限学生可以绕过限制，应用及网络过滤仍有覆盖缺口。
