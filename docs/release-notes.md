# ohno v0.1.0-alpha.2

相对 alpha.1 的新增功能：终端从 Windows 网卡信息读取稳定 MAC，优先物理有线永久地址，其次 Wi-Fi，并结合 SMBIOS UUID 识别克隆机器。教师端按 MAC 绑定审批并显示当前 MAC、MAC 冲突、最近连接 IP。DHCP 改变 IP 不影响身份；相同 MAC 不能代替设备独立密钥，也不会自动批准新设备。

**升级注意：教师端和学生端必须一起升级。** 旧版终端可能在首次启动新版时重新生成设备身份，需要教师重新批准；更换网卡也可能产生新设备记录。无法识别网卡 MAC 的终端不能注册。请先在隔离测试机验证，不要直接对真实课堂下发。


这是面向 Windows x64 的隔离测试预发布版，不应直接批量分发到真实课堂。安装器和教师程序未经过代码签名，Windows 可能提示发布者未知。

包含自包含学生端安装器和教师端程序：单服务自启动、随包 TUN、教师网页与设备审批、域名规则、游戏文件名/哈希规则、临时审批、教师密码临时解锁，以及对部分下载或 U 盘来源程序的实验性联网限制。安装和使用参见压缩包中的 `trial-guide.md`。

**重要限制：**学生拥有管理员权限时可绕过服务；游戏进程扫描存在启动窗口；下载来源标记、U 盘复制和脚本/委托联网无法可靠识别，WFP 只限制发现后新建的连接，不能作为防病毒隔离。TUN 对常见私有网段做排除，无法保证识别加密域名或覆盖全部流量。本地文件限制仅为 Edge 的试验功能，会影响课件，不能保证拦住所有 HTML 游戏。教师密码可能被学生管理员记录，建议使用远程审批。

Windows 自动化覆盖原生编译、安装/卸载、规则和程序扫描、WFP、Edge、TUN 及教师审批流程；尚未在兆芯机器和联想教育机增量镜像流程上实测。请先在可还原的单机上验证。
