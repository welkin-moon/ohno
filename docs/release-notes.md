# ohno v0.1.0-alpha.6

本版包含 alpha.5 的全部修复，并继续处理故障恢复和程序识别问题。

- 教师端状态写入失败时回滚内存修改，返回可重试错误；不会继续使用未保存的策略、设备审批或 PIN。
- 程序申请标签按完整 UTF-8 字符截短并清理非法字符；单条永久错误不再卡住后续申请，认证、限流和临时故障仍会重试。
- 哈希缓存核对文件标识和变更时间；同路径、同大小、同修改时间的替换文件不会继承旧哈希。
- 文件名规则在无法计算哈希时仍然生效，取消扫描时不会继续终止程序。无法验证哈希的程序不能使用哈希临时放行。
- 发布版本统一由 VERSION 文件读取，并核对发布提交标记，避免工作流内多个版本号不一致。

alpha.5 的修复也包含在本版中：

- 拒绝会破坏状态保存的无效 Unicode；异常 CSRF、过深 JSON 和截断请求返回明确错误。
- TLS 握手在有超时和并发限制的工作线程执行；监听口启动失败会释放已打开的端口。
- 合并重复申请和 PIN 解锁，迁移旧版重复待审批记录，优先回收已结束的历史记录。
- 完整验证规则和授权后再更新学生端缓存；服务启动时先恢复屏蔽规则并撤回缓存中的临时网站放行。
- 修复 WFP 程序哈希变化、重复扫描和暂停期间授权变化后的恢复。
- 修复安装器注册表字符串读取越界，收紧学校安装包地址校验并支持 IPv6 地址格式。
- cryptography 从 46.0.3 升级至 50.0.2，纳入上游安全修复。

构建通过 Linux / Windows CI，覆盖教师端测试、C++ 策略测试、WFP、Edge、命名管道、安装卸载、完整审批和 PIN 解锁、单文件打包及证书生成。附件提供 SHA256SUMS 校验文件。

教师端升级时保留原有 OhnoTeacher 状态和证书。客户端安装器暂不支持覆盖升级：先卸载旧版，再安装新版；在教师端停用旧设备记录后重新审批 MAC 绑定。

仍为隔离测试版。兆芯 Win10、联想增量镜像及学校实际网络环境尚未现场验证；学生拥有管理员权限时仍可绕过客户端控制。
