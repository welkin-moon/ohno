# ohno v0.1.0-alpha.4

这版把 alpha.3 里过度复杂的教师端鉴权拆掉重做。

- 教师管理页只绑定 `127.0.0.1:8765`，双击教师端后自动打开，**没有登录页、没有教师管理密码、没有 session cookie**。
- 学生设备 API 独立监听 `HTTPS :8443`，局域网可访问，但管理页面、策略编辑、设备审批和学校安装包下载全部不在这个入口提供。
- 本机管理 POST 继续使用随机 CSRF token，并检查 loopback/Host，防止浏览器被其他网页盲提交。
- “学生机现场临时解锁”改成独立、可选的 4–8 位数字课堂 PIN；默认关闭，只用于暂停限制 1 小时。PIN 以盐化哈希保存并做失败频率限制，与后台管理权限完全无关。
- alpha.3 客户端的旧 `password` JSON 字段暂时兼容，但语义已经是课堂 PIN；alpha.4 客户端发送新 `pin` 字段。
- 一键安装和 MAC/DHCP 设备识别逻辑保持不变。

仍是隔离测试版：兆芯 Win10、联想增量镜像、学校实际 DNS/防火墙环境尚未现场验证。管理员权限学生仍可绕过客户端控制。
