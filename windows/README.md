# Windows 10 兼容性检查与服务骨架

## 先在一台测试机检查

`ohno-check.cmd` 是只读检查，运行不需要 .NET，也不主动请求管理员权限。它查询系统版本、架构、BFE/防火墙等服务和常见系统工具，不会更改系统设置。请从资源管理器双击运行并提供窗口输出。它不能证明所有 WFP 接口可用、网络驱动兼容或后续安装一定成功。`where` 不可用时检查结果可能不准确。出于隐私，它不主动读取账号名、IP 或个人文件。

## 服务骨架

`service.cpp` 是原生 Win32 单服务的生命周期骨架：接收 SCM 启动、停止和关机消息。目前支持向教师端注册和轮询规则，仅有按文件名或哈希定期扫描并尝试终止进程的试验性拦截（并非启动前拦截），没有学生端教师密码验证；安装和服务崩溃恢复仅有试验性实现，也不能作为成品部署。

在仓库根目录的 Visual Studio x64 开发者命令行中，使用 Windows SDK 编译：

```
cl /utf-8 /std:c++17 /EHsc /W4 /MT /DUNICODE /D_UNICODE windows\service.cpp windows\agent.cpp windows\monitor.cpp windows\browser_policy.cpp windows\network_filter.cpp windows\request_pipe.cpp windows\tun_manager.cpp src\policy.cpp /Fe:ohno-service-prototype.exe advapi32.lib winhttp.lib bcrypt.lib wtsapi32.lib fwpuclnt.lib rpcrt4.lib iphlpapi.lib
```

构建需要编译器及 SDK，成品运行时按 `/MT` 静态链接 C/C++ 运行库，不需要另装 .NET 或 Visual C++ 再发行包。精简系统可能缺失 Windows 自身的基础组件，必须通过实机检查和测试。

安装器仅供隔离环境试验，不能用于真实教室镜像。

服务从注册表 `HKLM\SOFTWARE\Ohno` 的字符串值 `ServerUrl` 读取教师端 HTTPS 根地址，使用系统证书信任链；设备凭据在本机系统注册表生成，教师批准后开始轮询。原型使用物理网卡永久 MAC（优先有线）、SMBIOS UUID 共同锚定设备凭据，IP 地址变化不影响身份。若原系统不报告物理 MAC，则退回支持的网卡当前地址，若完全无法识别 MAC 则教师端拒绝绑定审批。主硬件锚变化时重建设备凭据并请求教师重新审批；没有 UUID 且没有可用 MAC 时拒绝注册。尚未验证兆芯机器的 UUID 是否存在且唯一，因此仍不能用于实际镜像分发。

进程检测存在启动后至扫描前的时间窗口，拒绝执行可能失败，不能作为恶意程序防护。网站规则通过 TUN 按可识别的域名拦截，并通过 Edge 的 URLBlocklist 补充；加密或无法识别的域名及排除的内网网段不保证覆盖。不会显示自定义提示；网站申请需要通过桌面快捷方式手动发起。来源联网限制仅有不完整的试验性实现。教师可选择对 Edge 尝试限制所有本地文件；它可能影响 PDF 和课件，且无法保证覆盖全部本地 HTML。

## 安装器试验代码

`setup.cpp` 和 `setup.rc` 可将服务嵌入一个原生安装程序。实验参数：`ohno-setup.exe --install https://teacher.example:8443 --certificate cert.pem`（自签证书）或省略 `--certificate`（证书已受信任）；移除：`ohno-setup.exe --remove`。程序要求管理员权限、创建自动启动服务并设置有限的 SCM 崩溃重启。指定 `--certificate` 会把所提供的自签证书加入计算机根证书存储，影响全系统的信任范围；只应在学校 IT 核验证书后使用。卸载时只移除由安装器新增的证书。当前只适用于构建与隔离测试，尚未验证完整卸载、镜像分发和学校实际环境。

策略在成功下载后缓存在受限注册表中；服务器离线时尝试继续执行缓存规则，但不沿用临时放行。若设备身份因硬件变化重建，会先清除本程序记录的 Edge 规则和缓存。断网期间的游戏申请只暂存在内存，重启服务后可能丢失。该机制尚需完整集成测试。

程序联网限制有实验性实现：周期性检查运行中的可执行文件，识别 NTFS 下载区域标记或当前可移动磁盘路径，并在 WFP 对该程序添加 IPv4/IPv6 出站连接阻断规则；教师可对哈希临时放行。**这不是可靠的防病毒功能**：扫描前已有连接可能发生；来源标记可以丢失；U 盘文件复制后可能失去来源；脚本/共享运行时及代理进程的联网不能可靠归属；服务停止时动态规则消失。仅供受控测试。

安装器会创建“ohno website request”公共桌面快捷方式。学生输入域名后，本机服务向教师端提交网站申请；教师批准后试验性地通过 Edge URLAllowlist 对该设备精确放行，过期或离线后移除。请求与放行目前只覆盖 Edge；服务重启时未同步的请求会丢失。

教师可通过本机窗口在线输入教师密码，暂时解除本机 ohno 限制一小时；断网时暂停失效。因为学生拥有管理员权限，他们可能读取或记录输入的密码，建议优先在教师端远程审批，并使用不复用的课堂密码。

TUN 使用随安装包携带的 sing-box 1.14.4（含 Wintun），由唯一 Windows 服务启动和管理；不需要目标机单独下载运行时。为了减少与教师端及学校局域网冲突，TUN 排除常见私有网段；系统管理员仍可停止进程或修改路由。教师端的设备列表显示最近心跳与 TUN 进程状态。
